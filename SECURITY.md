# Security

If you find a security problem in these examples, or in the Jam Jam API itself,
please report it through the contact page at <https://jam-jam.org/contact/>
rather than in a public issue. Do not include a real API key in your report.

If you ever paste a real API key by mistake (in an issue, a commit or a chat),
revoke it right away in the Jam Jam app (Settings, API keys) and create a new one.
